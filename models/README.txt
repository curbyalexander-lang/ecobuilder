u2netp.onnx is the background remover used when students upload their own pictures.
Upload this "models" folder to your GitHub repository next to the builder pages.

Model: U-2-Net (small version, U2-Netp) by Xuebin Qin et al., 2020 — https://github.com/xuebinqin/U-2-Net
License: Apache License 2.0 (see LICENSE-Apache-2.0.txt). ONNX file packaged by the rmbg-webgpu project.

If this file is missing, the builders download a public copy instead, so uploads still work.
